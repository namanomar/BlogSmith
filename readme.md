# BlogSmith: AI Blog Writer 

This application allows users to generate engaging blog posts based on a given topic and receive feedback from multiple AI agents: **Writer**, **Critic**, **SEO Reviewer**, **Legal Reviewer**, **Ethics Reviewer**, and **Meta Reviewer**. Each agent provides specialized feedback to ensure the content is optimized, legally compliant, ethically sound, and polished.

## Features

- **Topic Input**: Enter a blog topic, and the AI generates a blog post.
- **Multi-perspective Review**: The content is reviewed from multiple angles:
  - **Writer**: Generates the blog post based on the provided topic.
  - **Critic**: Provides constructive feedback and suggestions for improvement.
  - **SEO Reviewer**: Ensures the content is optimized for search engines.
  - **Legal Reviewer**: Checks the content for legal compliance.
  - **Ethics Reviewer**: Verifies the ethical soundness of the content.
  - **Meta Reviewer**: Aggregates feedback from all reviewers and provides final suggestions for refinement.

## Requirements

- Python 3.7+
- Streamlit
- `autogen`
